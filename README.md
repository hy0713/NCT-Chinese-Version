# NCT-Chinese-Version

《The New Campaign Trail》原生剧本精校简体中文版，保留英文与中英切换。

## 下载与启动

点击 **Code → Download ZIP** 并解压，安装 Python 3，然后双击 `start.bat`。
浏览器打开 http://localhost:8000/campaign-trail/index.html 。也可运行 `python server.py --open`。

## 内容

- 15 个内置年份／版本、32 位可玩总统候选人、105 种竞选搭档组合。
- 背景、人物、问题、回答、反馈、结局与原生界面完整中文；保留原英文数据与模拟机制。
- 统一术语、逐字段校订记录、288 条带来源离线历史与政治梗旁注。
- 独立语言包和完整性校验工具。社区 MOD 未包含。
